# Krillion TH

เกมพิมพ์คำตอบฉบับไทยที่ได้แรงบันดาลใจจาก Krillion.io เล่นในเบราว์เซอร์ได้โดยไม่ต้องมีเซิร์ฟเวอร์หรือบัญชีผู้เล่น

## สถานะข้อมูล

รุ่นนำร่องมี **40 โจทย์จากผลสำรวจ**: เรื่องไทย 20 ข้อ และเรื่องทั่วไป 20 ข้อ แต่ละข้อมีคำตอบที่แหล่งสำรวจเผยแพร่ 9–76 รายการ รวม 661 รายการ แต่ละรอบมี 7 ข้อ โดยสลับสัดส่วนไทยต่อทั่วไปเป็น 4:3 และ 3:4 จึงสมดุลเมื่อเล่นสองรอบติดกัน ข้อมูลสำรวจเป็นภาพในช่วงเวลาและกลุ่มตัวอย่างที่ระบุ ไม่ใช่ผลโหวตของผู้เล่นในเกม

โจทย์ฉบับร่างเดิม 100 ข้อและ 3,705 คำตอบยังเก็บไว้ใน `data/questions.json` แต่ไม่ได้ใช้เล่นหรือคิดคะแนน และไม่รวมใน static build เพราะยังไม่ได้ตรวจผลสำรวจที่เหมาะสมครบทุกคำตอบ

แหล่งที่ใช้และข้อจำกัดของแต่ละชุดอยู่ใน `data/survey-bank.json` และ [บันทึกการค้นคว้า](docs/survey-research.md) ผู้เล่นเปิดที่มา ช่วงเก็บข้อมูล กลุ่มตัวอย่าง จำนวนตัวอย่างที่ระบุและคำอธิบายฐานย่อย รวมถึงร้อยละของคำตอบได้ในหน้าเฉลย ข่าวและกระแสใช้ช่วยค้นหาโพลได้ แต่ยอดวิว ยอดขาย หรือความรู้สึกของผู้จัดทำไม่ใช่ผลสำรวจ

## กติกาคะแนน

ในแต่ละข้อ นำร้อยละของคำตอบที่ **แหล่งสำรวจเผยแพร่** มาเรียงจากมากไปน้อย แล้วกระจายอันดับลงห้าระดับ Plankton 10, Schooler 30, Rare 60, Deep Cut 85 และ One in a Krillion 100 คะแนน ตัวเลขร้อยละเท่ากันได้คะแนนเท่ากัน ระดับที่อาจไม่มีคำตอบขึ้นอยู่กับจำนวนร้อยละที่แตกต่างกัน คะแนนหนึ่งแต้มเท่ากับความลึก 10 เมตร

คะแนนเป็นวิธีแปลงอันดับสำหรับเกมเท่านั้น ไม่ใช่ความน่าจะเป็นหรือจำนวนผู้ตอบ และใช้เปรียบเทียบเฉพาะคำตอบที่รายงานเปิดเผยเท่านั้น รายการที่ไม่ได้เปิดเผยไม่ได้หมายความว่าไม่มีคนตอบ จึงไม่ให้คะแนนรายการดังกล่าว การข้ามหรือหมดเวลาได้ 0 แต้ม

ผลสำรวจบางแห่งใช้คำตอบแบบจัดกลุ่มหรืออนุญาตเลือกหลายข้อ กลุ่มและฐานตัวอย่างของแต่ละรายงานต่างกัน ตัวอย่างรวมที่ระบุอาจไม่ใช่ฐานย่อยของทุกคำถาม คลังนี้เก็บข้อจำกัดดังกล่าวไว้พร้อมข้อมูล ไม่คำนวณจำนวนผู้ตอบย้อนกลับจากร้อยละปัดเศษ

## เริ่มเล่นในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป ไม่มี dependencies ภายนอก

    npm run dev

เปิด http://127.0.0.1:4173 หรือกำหนดพอร์ตบน PowerShell ด้วย `$env:PORT = '4174'` ก่อนรัน หยุดเซิร์ฟเวอร์ด้วย Ctrl+C

Daily และ Endless มีรอบละ 7 ข้อ ข้อละ 25 วินาที พร้อมช่วงอ่านโจทย์ 3 วินาที เป็นเกมพิมพ์ตอบ มีตัวอย่างหนึ่งรายการเมื่อยังนึกไม่ออก เกมใช้ชื่อเรียกที่คัดไว้และเสนอคำแก้เมื่อสะกดใกล้เคียง คำที่ไม่อยู่ในรายการที่แหล่งเผยแพร่สามารถแก้แล้วลองใหม่ได้ก่อนหมดเวลา

ผล การตั้งค่า และตัวละครเก็บใน localStorage ของเบราว์เซอร์ ปฏิทิน Daily ใช้ America/New_York ตามต้นแบบ ประวัติคะแนนรุ่นก่อนที่ใช้การประเมินยังเก็บในเครื่อง แต่ไม่นำมารวมกับสถิติจากโพล และไม่เปิดให้เล่นต่อด้วยคะแนนเดิม

## ตรวจสอบ

    npm test
    npm run check
    npm run build
    npm run preview

Preview ของ static build เปิดที่ http://127.0.0.1:4174 โดยปริยาย `check` ตรวจรูปแบบ ข้อมูลที่จำเป็น และขั้นต่ำ 9 คำตอบต่อข้อของคลังสำรวจ รวมถึงตรวจโครงสร้างฉบับร่างเดิมด้วย การตรวจอัตโนมัติไม่สามารถยืนยันความถูกต้องหรือสิทธิ์ของแหล่งข้อมูลภายนอกแทนการอ่านต้นฉบับได้

## Vercel และ Git

`vercel.json` ใช้ Framework Preset แบบ Other รัน `npm run build` และเผยแพร่ `dist/` ซึ่งมีเฉพาะข้อมูลโพลที่ใช้งาน ไม่มี environment variables ที่แอปต้องใช้ สำหรับ Preview:

    npx --yes vercel deploy --environment preview

ตรวจ target และ Deployment Protection ก่อนแชร์ การเชื่อม GitHub กับ Vercel สำหรับ deploy อัตโนมัติเป็นการตั้งค่าแยก และการ push branch ที่เป็น production อาจกระตุ้น production deployment ได้

ข้อมูล localStorage ไม่ย้ายจาก localhost ไปยังโดเมน Vercel โดยอัตโนมัติ ไม่มีการส่งคำตอบผู้เล่นไปยังบริการภายนอก

## เพิ่มโจทย์สำรวจ

1. หาแหล่งต้นทางที่ระบุผลสำรวจจริง คำถาม/ขอบเขต ตัวเลข กลุ่มประชากร ช่วงเวลา และขนาดตัวอย่างที่ตรวจสอบได้ ตรวจเงื่อนไขการนำข้อมูลไปใช้ด้วย
2. เพิ่มโจทย์ใน `data/survey-bank.json` ระบุชื่อผู้สำรวจ ลิงก์ HTTPS กลุ่มตัวอย่าง จำนวนตัวอย่างรวม (ถ้ารายงานไม่ระบุ ให้บอกไว้) และข้อจำกัดของฐานย่อย รวมถึงร้อยละต้นฉบับของแต่ละคำตอบ ห้ามเติมค่าของตัวเลือกที่ไม่มีข้อมูล
3. ตรวจว่า label และ aliases ไม่ทำให้กลุ่มคำตอบผิดความหมาย และคำถามในเกมไม่อ้างกว้างกว่าโพล ต้องมีอย่างน้อยเก้าคำตอบที่รายงานและร้อยละที่แตกต่างกันอย่างน้อยสองค่า
4. เพิ่มเวอร์ชันคลังและรัน `npm test`, `npm run check`, `npm run build` จากนั้นทดลองเล่นจริงพร้อมตรวจแหล่งอ้างอิง

`src/survey.js` ตรวจโครงสร้างและคำนวณระดับจากร้อยละทุกครั้งที่ให้คะแนน ไม่มี fallback ไปใช้ tier ของคลังร่าง `src/game.js` ดูแลกติกาและตัวจับเวลา ส่วน `src/storage.js` จัดเก็บ snapshot ของรอบเดิมในเครื่อง

## ภาพ เสียง และงานศึกษา

ภาพฉากและตัวละครสร้างใหม่สำหรับโปรเจกต์ ดูรายละเอียดใน `assets/README.md` และ `assets/sources.json` เสียงสร้างด้วย Web Audio ชื่อแบรนด์และเสียงยังควรตรวจสิทธิ์ก่อนเผยแพร่ทั่วไป โปรเจกต์นี้ไม่ได้เป็นบริการของ Krillion.io

[รายงานวิเคราะห์ต้นฉบับ 500 ข้อ](docs/krillion-question-study.md) เป็นงานศึกษาก่อนเปลี่ยนระบบคะแนน ใช้โจทย์ย้อนหลังสาธารณะ 500 ข้อและทดลองเล่นต้นฉบับ 7 ข้อ ไม่ได้หมายความว่าทดลองเล่นต้นฉบับครบ 500 ข้อ
