# Krillion TH

เว็บเกมคำตอบหายากฉบับไทยสำหรับเล่นในเครื่อง ยึดประสบการณ์ภาพ การเล่น และเสียงจาก Krillion.io ก่อนนำไปปรับแต่งต่อ

## เปิดเล่น

ต้องใช้ Node.js 22 หรือใหม่กว่า โปรเจกต์ไม่มีแพ็กเกจภายนอกและไม่ต้องติดตั้ง dependencies

    npm run dev

เปิด http://127.0.0.1:4173 แล้วกด BEGIN DESCENT

บน PowerShell หากพอร์ตถูกใช้งานอยู่:

    $env:PORT = '4174'
    npm run dev

หยุดเซิร์ฟเวอร์ด้วย Ctrl+C หากต้องการเปิดให้เครื่องอื่นใน LAN ทดลอง ให้ตั้ง HOST เป็น 0.0.0.0 ก่อนรัน และใช้ IP ของเครื่องเซิร์ฟเวอร์ อนุญาตการเชื่อมต่อใน Windows Firewall ตามที่ระบบถาม

## เตรียมขึ้น Vercel

Vercel ใช้ Framework Preset แบบ Other และรัน npm run build ตาม vercel.json จากนั้นเผยแพร่ไฟล์ static ใน dist/ พร้อม rewrite สำหรับ /daily, /unlimited และ /unlimited/classic ไม่ต้องตั้ง environment variables หรือเปิดเซิร์ฟเวอร์ Node สำหรับเว็บไซต์ที่ขึ้นแล้ว

ตรวจ build ในเครื่องด้วย:

    npm run build
    npm run preview

เปิด http://127.0.0.1:4174 และหยุด preview ด้วย Ctrl+C หากพอร์ตถูกใช้ ให้ตั้งตัวแปร PORT ก่อนรันเหมือนตัวอย่างด้านบน preview นี้จำลองเส้นทางตาม vercel.json ในเครื่อง

หากใช้ Vercel CLI ให้ล็อกอินและเชื่อมโฟลเดอร์กับโปรเจกต์ Vercel ก่อน จากนั้นสร้าง Preview ด้วย:

    npx --yes vercel deploy --environment preview

ตรวจ target ในผลลัพธ์และตั้ง Deployment Protection ตามที่ต้องการก่อนแชร์ลิงก์ โปรเจกต์ Vercel ใหม่อาจมี Production deployment และโดเมนอัตโนมัติ จึงควรตรวจการเข้าถึง Production แยกด้วย

การเชื่อม GitHub สำหรับ deploy อัตโนมัติเป็นการตั้งค่าแยกในหน้า Vercel โปรเจกต์ ไม่เกิดขึ้นเพียงเพราะโฟลเดอร์มี Git remote อยู่แล้ว ส่วนไฟล์ใน outputs/, docs/ และ data/archive/ จะไม่รวมในไฟล์ static ที่เผยแพร่

ความคืบหน้าเกมเก็บอยู่ใน localStorage ของแต่ละเบราว์เซอร์ ข้อมูลที่เล่นบน localhost จึงไม่ย้ายไปยังโดเมน Vercel อัตโนมัติ

## สิ่งที่เล่นได้

- Daily: รอบละ 7 ข้อ ข้อละ 25 วินาที มีช่วงอ่านโจทย์ก่อนเริ่มจับเวลา 3 วินาที เล่นเก็บผลได้วันละหนึ่งครั้งต่อคลังแต่ละเวอร์ชันในเบราว์เซอร์
- Endless: เล่นต่อเนื่องรอบละ 7 ข้อ จดจำโจทย์แยกกลุ่มไทยและทั่วไปเพื่อใช้ให้ครบแต่ละกลุ่มก่อนวนซ้ำ แต่ละรอบพยายามให้มีอย่างน้อย 5 หมวด และหมวดเดียวกันไม่เกิน 2 ข้อ
- แก้คำตอบที่ไม่พบในคลังได้ก่อนหมดเวลา รองรับชื่อเรียกอื่นและการเสนอคำแก้เมื่อสะกดใกล้เคียง โดย token สั้นรับเฉพาะชื่อ/alias ที่ระบุ
- คะแนน 6 ระดับ: Plankton 10, Too Clever 15, Schooler 30, Rare 60, Deep Cut 85 และ One in a Krillion 100 ทุกคะแนนเท่ากับความลึก 10 เมตร
- ฉากผิวน้ำ/ทะเล คำตอบและตัวละครดำผ่านเส้นแต่ละระดับพร้อมเสียง ฟองอากาศ และความลึกที่เคลื่อนตามกัน ก่อนหยุดและแสดงผล
- Settings: low-power mode, colorblind mode, answer corrections, clear rejected entries, share link และ mute
- หน้าผลคะแนน แชร์ข้อความโดยไม่เปิดเผยคำตอบ ประวัติในเครื่อง และตัวละครที่ปลดล็อกจากการเล่น
- เฉลยพร้อมเกร็ดความรู้ แหล่งอ้างอิง และหลักฐานความคุ้นเคยที่มีข้อมูล

ปฏิทิน Daily ใช้ America/New_York ตามต้นแบบ รวมการเปลี่ยนเวลาออมแสง เปลี่ยนค่า TIME_ZONE ใน src/game.js เมื่อต้องการปรับเป็น Asia/Bangkok ในรอบปรับแต่ง และควรออกเวอร์ชันข้อมูล/คีย์บันทึกใหม่เมื่อเปลี่ยนกติกาวัน

ความคืบหน้า ผลคะแนน การตั้งค่า และตัวละครอยู่ใน localStorage ของเบราว์เซอร์ เก็บประวัติการเล่นล่าสุด 40 รอบเพื่อลดการใช้พื้นที่ ล้างข้อมูลไซต์แล้วข้อมูลในเครื่องจะหาย ไม่มีการซิงก์หรือส่งคำตอบไปยัง Krillion.io ระบบนี้ไม่มีฐานข้อมูลกลาง อันดับผู้เล่นออนไลน์ ระบบเพื่อน Puffer Party หรือการซื้อแพ็ก

## แหล่งข้อมูลและวิธีให้คะแนน

คลังปัจจุบันอยู่ที่ data/questions.json มี 100 โจทย์ (ไทย 70 / ทั่วไป 30) รวม 3,705 คำตอบ ครอบคลุมอาหาร ชีวิตประจำวัน ความบันเทิง สัตว์ กีฬา ดนตรี และสถานที่ที่ผู้เล่นไทยคุ้นเคย แต่ละรอบใช้ไทย 5 ข้อและทั่วไป 2 ข้อ ทุกคำตอบมีชื่อมาตรฐาน ระดับคะแนน เหตุผลประกอบ และแหล่งข้อมูลระดับโจทย์ พร้อม aliases เมื่อมีชื่อเรียกอื่นที่คัดไว้

ดู [รายงานวิเคราะห์ต้นฉบับ 500 ข้อ](docs/krillion-question-study.md) สำหรับวิธีเลือกตัวอย่าง ผลการจัดหมวด และเหตุผลที่เปลี่ยนคลังเดิม งานวิจัยนี้ใช้โจทย์ย้อนหลังสาธารณะ 500 ข้อและเล่นเว็บต้นฉบับจริง 7 ข้อ ไม่ได้อ้างว่าเล่นต้นฉบับครบ 500 ข้อ

ยึดหลักที่ผู้สร้างอธิบายใน https://krillion.io/faq คือรวบรวมคำตอบจากแหล่งอ้างอิง ประเมินความคุ้นเคย และตรวจทานก่อนเผยแพร่ คะแนนของโปรเจกต์นี้เป็นการจัดระดับของคลังเราเอง ไม่ได้อ้างว่าเป็นสูตรลับหรือค่าความหายากเดียวกับต้นแบบ

data/evidence.json เก็บข้อมูลยอดอ่าน Wikipedia ภาษาไทย 40 บทความจากคลังเดิมย้อนหลัง 12 เดือนเต็ม โดยใช้ Wikimedia Analytics API (all-access/user/monthly) คำตอบในโจทย์ใหม่ 79 ข้อยังไม่ได้ผูกบทความหรือมียอดอ่านรองรับ คะแนนชุดใหม่นี้เป็นการประเมินของผู้จัดทำ

ยอดอ่านเป็นตัวช่วยประกอบการประเมิน ไม่ใช่อัตราที่ผู้เล่นตอบหรือเปอร์เซ็นต์คนไทยที่รู้คำตอบ บทความภาษาไทยมีผู้อ่านจากหลายประเทศ และความสนใจช่วงข่าวอาจต่างจากความคุ้นเคยทั่วไป ตัวเลขที่หาไม่ได้เก็บเป็น missing/error ไม่แทนด้วย 0 และไม่ให้คะแนนสูงอัตโนมัติ

ชื่อเฉพาะที่ไม่มีบทความตรงความหมายอาศัยการจัดระดับพร้อมเหตุผล ไม่ฝืนใช้ยอดอ่านบทความที่หมายถึงคนละสิ่ง คำตอบ Krillion เป็นคำตอบพิเศษหนึ่งรายการต่อข้อที่เลือกเพื่อให้สนุกและน่าจดจำ ไม่จำเป็นต้องมียอดอ่านน้อยที่สุด

ดู [บันทึกเนื้อหา](data/CONTENT-NOTES.md) สำหรับจำนวนคำตอบ ขอบเขตของแต่ละข้อ และแหล่งอ้างอิง ชุดที่คัดเลือก เช่น หนังหรืออาหาร ยังเพิ่มคำตอบจริงได้ ส่วนชุดปิด เช่น จังหวัดและโปเกมอน ตรวจจำนวนให้ครบตามขอบเขตที่ระบุ

## ปรับปรุงคลัง

1. เพิ่มหรือแก้โจทย์/คำตอบใน data/questions.json ใช้ id ที่ไม่ซ้ำ ระบุ theme มีอย่างน้อย 25 คำตอบ หลายระดับคะแนน Krillion หนึ่งรายการต่อข้อ และ starterAnswers ที่ยอมรับจริงอย่างน้อย 5 ชื่อ
2. ใส่ aliases ที่ตรงความหมาย ห้ามให้ alias เดียวกันชี้หลายคำตอบในโจทย์เดียวกัน
3. ถ้ามีบทความภาษาไทยที่ตรงสิ่งนั้น ให้ระบุชื่อ canonical ใน wikiTitle หากไม่มีให้ใช้ null
4. เปลี่ยน questionVersion เมื่อขอบเขตโจทย์เปลี่ยน และเปลี่ยน version ของคลังเมื่อเผยแพร่ชุดใหม่
5. ดึงข้อมูลใหม่ด้วย npm run refresh-data ตรวจข้อมูลและเหตุผลประกอบก่อนแก้ระดับคะแนน สคริปต์ไม่แก้คะแนนให้อัตโนมัติ

    npm run refresh-data
    node scripts/refresh-evidence.mjs --as-of=2026-11-17
    node scripts/refresh-evidence.mjs --as-of=2026-11-17 --reuse-complete

สคริปต์ดึงเฉพาะชื่อบทความที่ระบุในคลังปัจจุบัน และอาจใช้หลายนาทีตาม rate limit สคริปต์รอตาม Retry-After และเก็บสถานะผิดพลาดอย่างตรงไปตรงมา ตัวเลือก --reuse-complete ใช้ข้อมูลเดิมได้เฉพาะชื่อ URL ช่วงเดือน และผลรวมที่ตรวจว่าตรงและครบ ใช้ WIKIMEDIA_USER_AGENT ตั้งชื่อโปรแกรม/ข้อมูลติดต่อที่เหมาะสมได้ก่อนใช้งานจริง

รอบที่เริ่มแล้วมี snapshot ของโจทย์ คำตอบและคะแนน จึงไม่เปลี่ยนย้อนหลังเมื่อแก้คลัง เมื่อเปลี่ยนเวอร์ชัน ผู้เล่นเริ่ม Daily ชุดใหม่ได้ในวันเดิม ประวัติ การตั้งค่า และตัวละครยังอยู่ รอบเก่าที่ยังไม่จบเปิดเล่นต่อผ่าน Dive log ได้ โดยเวลาของข้อที่ค้างยังเดินตามเดิม ระบบเก็บสำเนาโจทย์ที่เหมือนกันร่วมกันเพื่อลดพื้นที่เมื่อคลังคำตอบใหญ่ขึ้น และยังอ่าน save รูปแบบเดิมได้ ชุดคำถามและหลักฐานรุ่นแรกเก็บไว้ใน data/archive/

## ตรวจสอบ

    npm test
    npm run check

ชุดทดสอบครอบคลุมความหลากหลายและการไม่ซ้ำของโจทย์ ชื่อและ aliases ทุกคำตอบ จำนวนชุดปิด วันตาม New York/DST เส้นตาย การส่งซ้ำ การหมดเวลาเมื่อสลับแท็บ การเล่นครบ 7 ข้อ การแชร์ และการย้าย save ระหว่างเวอร์ชัน ส่วน check ตรวจครบทั้งคลัง คะแนน แหล่งอ้างอิง และข้อมูลหลักฐานที่มีอยู่

เปิดเครื่องมือพัฒนาแล้วเลือกขนาด 1280×900 และ 390×844 เพื่อตรวจทั้ง desktop/mobile การกด Tab/Escape ใช้งานได้ใน dialog และภาพเคลื่อนไหวลดลงตาม prefers-reduced-motion

## โครงสร้าง

- src/game.js: กติกา ตัวจับเวลา ตรวจคำตอบ จัดโจทย์ และสร้างข้อความแชร์
- src/app.js: หน้าจอ การโต้ตอบ dialog และการเชื่อมข้อมูลบันทึก
- src/input.js: คืนโฟกัสและตำแหน่งเคอร์เซอร์เมื่อแก้คำตอบ
- src/scene.js: ฉากทะเล depth ruler ฟองอากาศและสัตว์น้ำ
- src/descent.js: ระยะเวลาและตำแหน่งการจมที่ใช้ร่วมกันระหว่างฉากกับระดับคะแนน
- src/audio.js: Web Audio engine ที่จัดทำขึ้นใหม่
- src/storage.js: localStorage และค่าเริ่มต้น
- assets/audio-cues.json: ตารางค่าความถี่ ช่วงเวลา filter และ envelope ที่ใช้เทียบเสียงต้นแบบ
- scripts/server.mjs: static server สำหรับพัฒนา ไม่มี API และไม่ส่งคำตอบออก
- scripts/build.mjs และ scripts/preview-build.mjs: สร้างและทดลองไฟล์ static สำหรับ Vercel
- scripts/refresh-evidence.mjs: ดึงหลักฐานยอดอ่านล่วงหน้า
- scripts/analyze-reference.mjs: เลือกและจัดหมวดตัวอย่างโจทย์จากคลังสาธารณะ
- docs/krillion-question-study.md: รายงานผลวิเคราะห์และแนวทาง localization

## ภาพและเสียง

ภาพฉากและตัวละครที่เกมใช้สร้างใหม่ด้วย imagegen โดยไม่ได้ส่งภาพต้นแบบเป็น input ดู prompt และที่มาใน assets/README.md และ assets/sources.json ฟอนต์ VT323 และ Sarabun แนบ OFL มาด้วย

ระบบเสียงเขียนขึ้นใหม่จากตารางค่าตัวเลขตามเหตุการณ์ที่ตรวจพบในต้นแบบ จึงยังควรตรวจสิทธิ์การใช้เสียงและชื่อเกมก่อนเปิดเผยแพร่ทั่วไป ในโมดูลเสียงที่ตรวจมี 16 cues และไม่พบเพลงวนต่อเนื่อง

ชื่อแบรนด์ เมนูภาษาไทย เสียง และปฏิทินด่านยังปรับต่อได้ โปรเจกต์นี้เป็นงานแยกและไม่ได้เป็นบริการของ Krillion.io
