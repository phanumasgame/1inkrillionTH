# วิเคราะห์โจทย์ Krillion.io และแนวทางคำถามฉบับไทย

เอกสารนี้บันทึกการวิเคราะห์และผลของคลังรุ่น 21 ข้อในขณะนั้น ปัจจุบันคลังขยายเป็น 100 ข้อแล้ว ดูจำนวนและข้อจำกัดปัจจุบันที่ [บันทึกเนื้อหา](../data/CONTENT-NOTES.md)

ตรวจเมื่อ 17 พฤศจิกายน 2026 เพื่อแก้ปัญหาคลังเดิมที่ให้ความรู้สึกเหมือนแบบฝึกหัด โดยคงหน้าตา จังหวะการเล่น และระบบเสียงของโปรโตไทป์ไว้

## ขอบเขตหลักฐาน

**วิเคราะห์โจทย์ย้อนหลังสาธารณะ 500 ข้อ และเล่น Daily บนเว็บต้นฉบับจริง 7 ข้อ** ไม่ได้เล่นต้นฉบับครบ 500 ข้อ

ในเซสชันที่ไม่มี Unlimited การเปิด Archive และ Unlimited หลังรอบฟรีพบหน้าปลดล็อกและ HTTP 402 ผู้ใช้อนุญาตให้ใช้โจทย์ย้อนหลังสาธารณะประกอบ จึงใช้ [ตารางรวมของ Hints4Today](https://hints4today.com/krillion-unlimited-answers/) ซึ่งระบุว่าเป็นโจทย์ของ Krillion.io พร้อมลิงก์วันและ dive รายข้อ แหล่งนี้เป็นผู้รวบรวมอิสระ ไม่ใช่ผู้พัฒนาเกม ดู [วิธีรวบรวม](https://hints4today.com/krillion-methodology/) และ [หน้า archive](https://hints4today.com/krillion-archive/)

ตารางที่ตรวจมีข้อความโจทย์ไม่ซ้ำ 875 ข้อ จาก 125 dives ช่วง 16 กรกฎาคม–17 พฤศจิกายน 2026 เลือก 500 ข้อด้วยลำดับ SHA-256 และ seed คงที่หลังตัดข้อความซ้ำ การเลือกไม่อิงจำนวนคำตอบหรือเลือกเฉพาะโจทย์ที่ชอบ อย่างไรก็ตาม ชุดนี้ยังขึ้นกับความถูกต้องและความครบของผู้รวบรวม จึงไม่ถือเป็นตัวอย่างสุ่มจากฐานข้อมูลส่วนตัวทั้งหมดของผู้สร้าง

ตรวจเทียบข้อความทั้ง 7 ข้อของ Daily #125 กับข้อมูลที่หน้าเว็บทางการโหลดในวันเดียวกัน พบตรงกันทั้ง 7 ข้อเมื่อไม่นับเครื่องหมายท้ายประโยค นี่เป็นการตรวจยืนยันเฉพาะวันดังกล่าว ไม่ใช่การรับรองย้อนหลังครบ 500 ข้อ

- [ผลตัวอย่าง 500 ข้อพร้อม hash และลิงก์ย้อนกลับ](research/reference-sample-500.json)
- [หลักฐานการเล่นต้นฉบับจริง 7 ข้อ](research/official-play-validation.json)
- ทำซ้ำได้ด้วย npm run analyze-reference โดยผลอาจเปลี่ยนเมื่อเว็บแหล่งข้อมูลเพิ่มหรือแก้ตาราง

ไฟล์ผลเก็บหมวด tag hash วัน และลิงก์ ไม่ได้แจกชุดข้อความโจทย์ทั้งหมดหรือคำตอบของต้นฉบับ คลังไทยที่ใช้ในเกมเขียนใหม่

## ต้นฉบับถามเรื่องอะไร

หมวดต่อไปนี้เป็นการจัดของโปรเจกต์นี้ด้วยกฎหัวข้อและการตรวจรายการที่กำกวม ไม่ใช่หมวดที่ผู้สร้างเผยแพร่ หนึ่งข้ออยู่ในหนึ่งหมวดหลัก แม้บางข้อเกี่ยวข้องหลายเรื่อง

| แนวคำถาม | จำนวน | สัดส่วน |
|---|---:|---:|
| สถานที่และภูมิศาสตร์ | 102 | 20.4% |
| สิ่งของและชีวิตประจำวัน | 68 | 13.6% |
| อาหารและเครื่องดื่ม | 65 | 13.0% |
| ธรรมชาติและสัตว์ | 56 | 11.2% |
| หนัง ซีรีส์ และตัวละคร | 52 | 10.4% |
| แบรนด์และเทคโนโลยี | 40 | 8.0% |
| วิทยาศาสตร์และร่างกาย | 34 | 6.8% |
| กีฬา | 24 | 4.8% |
| หนังสือ ภาษา และประวัติศาสตร์ | 24 | 4.8% |
| เพลงและดนตรี | 19 | 3.8% |
| เกม | 16 | 3.2% |
| รวม | 500 | 100% |

ความยาวมัธยฐาน 7 คำภาษาอังกฤษ สั้นที่สุด 3 คำ ยาวที่สุด 26 คำ จึงเห็นแนวโน้มการถามสั้น เข้าใจขอบเขตได้เร็ว แล้วให้ผู้เล่นค้นความทรงจำของตัวเอง

กฎเสริมที่พบจากการติด tag แบบไม่แยกขาดจากกัน:

- 269 ข้อ (53.8%) เข้าเกณฑ์รูปประโยคเรียกสมาชิกของหมวดแบบตรงไปตรงมา
- 37 ข้อ (7.4%) มีกฎตัวอักษรหรือการสะกด
- 49 ข้อ (9.8%) มีกฎจำนวน ตัวเลข ปี หรือความยาว
- 12 ข้อ (2.4%) ติดคำสำคัญของรายการความรู้เฉพาะตามกฎที่ใช้

ตัวเลขสุดท้ายไม่ใช่ “มีคำถามวิชาการเพียง 2.4%” เพราะตัวกรองนี้ตรวจเพียงคำสำคัญบางชุด และ tag สามารถซ้อนกันได้ การวิเคราะห์นี้ไม่วัดความยากจริง อัตราตอบถูก หรือความถี่คำตอบของผู้เล่น

## สิ่งที่เห็นจากการเล่นจริง

Daily #125 สลับบริบทตลอด 7 ข้อ: หนังที่มีสัตว์พูดได้ อาหารหรือเครื่องดื่มตามเงื่อนไขการสะกด สัตว์ตามความยาวชื่อ นักกีฬาที่เลิกเล่น เมืองตามรูปแบบชื่อ ผักผลไม้ที่เนื้อในขาว และตัวละครจากเกมที่ระบุ

ส่งคำตอบที่คุ้นเคย ได้แก่ The Lion King, espresso, elephant, Michael Jordan, Pittsburgh, apple และ Jett ต้นฉบับยอมรับทั้ง 7 คำตอบ จบรอบได้ 110 คะแนน / 1,100 เมตร ข้อสังเกตคือ “ตอบได้” กับ “ได้คะแนนสูง” เป็นคนละเรื่อง การเริ่มจากสิ่งที่คุ้นทำให้คนกล้าตอบ แล้วค่อยพยายามหาคำที่คนอื่นไม่ค่อยนึกถึงในรอบถัดไป

นี่เป็นหลักฐานของรอบเดียว ไม่เพียงพอจะสรุปคะแนนทั้งหมดหรือสูตรความหายากภายในของผู้สร้าง

## เหตุใดคลังเดิมจึงเหมือนแบบฝึกหัด

คลังเดิมมี 21 ข้อ แต่มี 8 ข้อเป็นการกรองรายชื่อจังหวัด และ 3 ข้อเป็นอักษรสูง–กลาง–ต่ำ ส่วนโจทย์โลกทั้ง 6 ข้อเป็นชุดความรู้แบบตำรา เช่น หน่วย SI ธาตุ ดาวเคราะห์ และ NATO จึงซ้ำทั้งอารมณ์และวิธีคิด แม้แต่ละข้อจะตรวจข้อเท็จจริงได้

เดิมมีคำตอบรวม 213 รายการ เฉลี่ยประมาณ 10.1 รายการต่อข้อ ชุดเล็กหลายข้อทำให้ผู้เล่นต้องจำรายการที่เฉพาะเจาะจง ขณะที่โจทย์ต้นฉบับจำนวนมากเปิดจากหมวดที่คนพบในชีวิตและความบันเทิง

ต้นฉบับยังมีโจทย์วิทยาศาสตร์ ภูมิศาสตร์ และกฎการสะกด จึงไม่จำเป็นต้องตัดความรู้ออกทั้งหมด สิ่งที่ต้องปรับคือสัดส่วนหมวด ความกว้างของคำตอบ และภาษาที่ชวนให้นึก มากกว่าถามให้ท่อง

## การปรับใช้กับเกมไทย

เปลี่ยนทั้ง 21 ข้อ ใช้บริบทผู้เล่นไทย 15 ข้อและความรู้ทั่วไป 6 ข้อเหมือนสัดส่วนที่ตกลงไว้ แต่เปลี่ยนเป็นอาหารที่สั่ง ขนม เครื่องดื่ม ของในร้านสะดวกซื้อ แบรนด์ เกมวัยเด็ก หนัง วงดนตรี รายการทีวี งานประเพณี และสถานที่เที่ยว ผสมกับสัตว์ เกม โปเกมอน กีฬา เครื่องดนตรี และโทรศัพท์

| เดิม | วิธีเขียนใหม่ |
|---|---|
| จังหวัดที่ตรงเงื่อนไขพยัญชนะหรือพรมแดนหลายข้อ | ชวนเพื่อนไปเที่ยวจังหวัดไหนดี และสถานที่ที่นึกถึงได้จากประสบการณ์ |
| แยกอักษรสูง–กลาง–ต่ำ | เกมวัยเด็ก ของกิน และแบรนด์ที่คุ้น |
| รายชื่อหน่วย SI หรือรหัส NATO | สัตว์ เครื่องดนตรี กีฬา และเกมที่ผู้เล่นเคยพบ |
| ชุดคำตอบเฉลี่ยประมาณ 10 รายการ | ขยายคลังคำตอบ พร้อมชื่อเล่น ชื่อไทย และชื่ออังกฤษที่ตรงสิ่งเดียวกัน |

แนวทางตรวจคำถามใหม่:

1. อ่านแล้วเข้าใจได้ทันที มีชื่อคุ้นเคยอย่างน้อย 5 ชื่อเป็นจุดเริ่ม และไม่แสดงตัวอย่างคำตอบบนหน้าจอระหว่างจับเวลา
2. ภาษาสั้นเป็นธรรมชาติ ไม่แปลกฎตัวอักษรอังกฤษให้กลายเป็นข้อสอบภาษาไทยโดยอัตโนมัติ
3. ขอบเขตตรงกับคลัง เช่น BTS ระบุสายสุขุมวิท–สีลม และโปเกมอนระบุ 151 ชนิดแรก ไม่เปิดกว้างเกินคำตอบที่รองรับ
4. แยกชุดปิดที่ตรวจครบได้ เช่น จังหวัดหรือโปเกมอน ออกจากชุดคัดเลือกที่เพิ่มได้ เช่น หนังและอาหาร คำตอบจริงที่ยังไม่อยู่ในชุดเปิดเป็นช่องว่างของคลัง
5. รับ alias ที่ตรงความหมาย ตรวจไม่ให้ชื่อเดียวชี้หลายคำตอบในโจทย์เดียวกัน
6. จัดรอบให้มีอย่างน้อย 5 หมวด และไม่เกิน 2 ข้อต่อหมวด พร้อมรักษาสัดส่วนไทย 5 / โลก 2 และเล่น Endless ครบคลังก่อนซ้ำ

คะแนนของฉบับไทยยังเป็นการประเมินเชิงบรรณาธิการพร้อมเหตุผลต่อคำตอบ ไม่ได้อ้างว่าเป็นสถิติการตอบจากผู้เล่นไทย 500 คน ยอดอ่าน Wikipedia ที่มีเป็นหลักฐานเสริมเฉพาะบทความที่ตรงสิ่งนั้น และไม่แปลงยอดอ่านน้อยหรือข้อมูลที่หายไปเป็นคะแนนสูงอัตโนมัติ

การทดสอบครั้งนี้ยืนยันโครงสร้างและการยอมรับคำตอบที่กำหนดไว้ แต่ยังต้องอาศัยการลองเล่นของคนไทยเพื่อปรับ tier และเพิ่มคำตอบจริงที่นอกคลังคัดเลือก

## ผลที่นำเข้าโปรโตไทป์แล้ว

คลัง 2026.11.17.2 เปลี่ยนคำถามครบ 21 ข้อ มีคำตอบมาตรฐาน **1,308 รายการ** จากเดิม 213 รายการ เฉลี่ย 62.3 คำตอบต่อข้อ มีชื่อและ alias รวม 4,519 รายการ และ 9 themes ดู [ขอบเขตพร้อมจำนวนรายข้อ](../data/CONTENT-NOTES.md) และแหล่งอ้างอิงที่แนบไว้

ตรวจชื่อและ aliases ผ่าน matcher จริงทั้งหมด ทดสอบ Daily 366 วัน และ Endless 60 seeds × 3 รอบ เพื่อยืนยันความหลากหลายพร้อมการใช้ครบคลังก่อนซ้ำ ชุดทดสอบล่าสุด 38 ข้อผ่าน และ data check ผ่าน

เล่นฉบับไทยผ่านหน้าจอจริงครบ 7 ข้อด้วยคำตอบคุ้นเคย ได้ 70 คะแนน / 700 เมตร ผลอยู่หลังรีเฟรช ตรวจหน้าเฉลยและหน้าจอ 1280×900 กับ 390×844 ไม่พบการล้นแนวนอน ตรวจด้วย fixture ของ save เดิมว่าประวัติ คะแนน การตั้งค่า และตัวละครอยู่ครบ เปิดชุดใหม่ได้และย้อนเล่นรอบเก่าผ่าน Dive log ได้

ทดสอบการเก็บประวัติจำลอง 40 รอบใน localStorage จริง: ข้อมูลก่อนลดความซ้ำมี 4,493,661 UTF-16 code units เหลือ 410,615 code units โดยเก็บสำเนาโจทย์ 21 รายการร่วมกันและอ่านกลับได้เหมือนเดิมทุกค่า ตัวเลขนี้เป็นการทดสอบพื้นที่จัดเก็บ ไม่ใช่การเล่นผ่านหน้าจอ 40 รอบ

หลักฐานยอดอ่านมี 40 บทความจาก 1,308 รายการคำตอบ ครบ 12 เดือนทุกรายการ ข้อมูลนี้เป็นเพียงส่วนเสริมของคลังคัดเลือก คะแนนส่วนใหญ่ยังอาศัยเหตุผลเชิงบรรณาธิการตามที่เปิดเผยไว้ ไม่ได้เป็นผลสำรวจผู้เล่น
